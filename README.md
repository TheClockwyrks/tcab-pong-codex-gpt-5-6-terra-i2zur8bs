# Carom

Carom is a top-down paddle duel where moving your paddle at impact adds spin to
the ball. Curve rallies through the rotating center gates, find a bank shot, and
win by two.

## Run it

Install dependencies with `npm ci`, then launch the development server with
`npm run dev`. Build the standalone static site into `dist/` with
`npm run build`; inspect that build locally with `npm run preview`.

## Controls

- Player one: `W` / `S`
- Player two: `Arrow Up` / `Arrow Down`
- Menus: `W` / `S`, arrows, `Enter`, or `Space`
- Pause: `P` or `Escape`
- Mute: `M`

Solo puts the right paddle under an AI opponent; Versus is local two-player.
